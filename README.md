Taller Mecánico - Sistema de Gestión de Citas

Configuración de la base de datos

Requisitos:
- XAMPP instalado
- MySQL iniciado desde XAMPP

Importar la base de datos:

1. Abrir XAMPP
2. Iniciar MySQL
3. Entrar a http://localhost/phpmyadmin
4. Ir a la pestaña SQL
5. Copiar y pegar el contenido de database/taller.sql
6. Ejecutar

Verificación:

- Debe existir la base de datos: taller_mecanico
- Tablas: citas y configuracion
- `configuracion` debe contener servicios, técnicos, estados y marcas
